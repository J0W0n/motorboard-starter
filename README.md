# MOTORBOARD · 모터보드

AI Agent와 함께 기존 프로젝트를 개선하는 **중고차 게시판 실습 시작 코드**입니다.
차량 목록과 상세 조회는 완성되어 있고, **차량 추가·JSON 저장은 학생이 구현할 과제**로 남겨두었습니다.

## 준비

- VS Code (기존 수업 환경)
- Node.js 22 이상. 팀 검증 환경: Node.js 24
- VS Code에서 GitHub Copilot Agent 사용 가능 여부와 계정 사용 한도 확인
- 웹 브라우저

HTML, CSS, JavaScript와 Node.js 기본 모듈만 사용합니다.
**외부 패키지가 없으므로 `npm install` 없이 실행할 수 있습니다.** DB, Excel, API Key도 필요하지 않습니다.
Copilot 이용에는 인터넷이 필요하지만, 사이트 자체에는 외부 폰트·사진·API 요청이 없습니다.

## 시작하기

1. VS Code에서 `package.json`이 있는 프로젝트 폴더를 엽니다.
2. VS Code 터미널에서 확인하고 실행합니다.

```sh
node --version
npm start
```

3. 브라우저에서 **http://127.0.0.1:3000**을 엽니다.
4. 종료할 때는 터미널에서 **Ctrl+C**를 누릅니다.

파일을 수정하면서 서버를 자동 재시작하려면 `npm run dev`를 사용할 수 있습니다.
HTML·CSS·브라우저 JavaScript는 저장 후 브라우저를 새로고침하세요.
`index.html`을 파일로 직접 열거나 Live Server로 실행하지 마세요. 조회 API를 제공하는 Node.js 서버가 필요합니다.

PowerShell에서 npm.ps1 실행 정책 오류가 나타나면 시스템 정책을 바꾸지 않고 `npm.cmd start` 또는 `node server.js`로 실행하세요.

## 들어 있는 기능

- JSON 데이터 기반 차량 목록과 상세 조회
- 연식, 주행거리, 연료, 변속기, 지역, 옵션, 판매자 설명
- 가상 판매자 연락처
- 모바일 대응, 키보드 탐색, 로딩·빈 목록·오류 안내
- 모든 차량용 로컬 SVG 일러스트

차량 정보·가격·사양은 학습용 가상 데이터이며 실제 시세를 나타내지 않습니다.
차량 일러스트는 이 프로젝트를 위해 작성한 일반 차량 그림이며 실제 차종 사진이 아닙니다.
판매자 이메일은 `example.com`, 전화번호는 마스킹된 예시를 사용합니다.

## 파일 구조

```text
motorboard-starter/
├─ server.js                 # 정적 파일과 조회 API를 제공하는 서버
├─ src/car-store.js          # JSON 읽기와 차량 한 대 찾기
├─ data/cars.json            # 가상 차량 6대 (실제 저장 대상)
├─ public/
│  ├─ index.html             # 목록 화면
│  ├─ car.html               # 상세 화면
│  ├─ styles.css             # 화면 디자인과 반응형 배치
│  ├─ js/list.js             # 목록 API 호출과 카드 표시
│  ├─ js/detail.js           # 상세 API 호출과 정보 표시
│  ├─ js/shared.js           # 공통 표시 함수와 오류 안내
│  └─ assets/                # 로컬 차량 SVG, 아이콘
├─ test/server.test.js       # 기존 기능을 확인하는 테스트
├─ docs/EXERCISES.md         # 실습 순서, 요청 예시, 완료 기준
├─ docs/DATA.md              # 차량 데이터 형식
├─ AGENTS.md                # AI 작업 기준
└─ .github/copilot-instructions.md
```

목록 흐름: `list.js → GET /api/cars → car-store.js → cars.json → 카드 표시`

상세 흐름: `car.html?id=MB-001 → detail.js → GET /api/cars/MB-001 → 상세 표시`

현재 API는 다음 두 가지입니다.

- `GET /api/cars`: `{ "cars": [...] }`
- `GET /api/cars/:id`: `{ "car": {...} }`, 없는 차량은 404

`POST /api/cars`는 현재 405를 반환합니다. 실습에서 구현할 자리이며 고장이 아닙니다.

## 실습 진행

1. 프로젝트를 실행하고 AI에게 구조와 데이터 흐름을 설명하게 합니다.
2. 작은 개선 과제 하나를 진행합니다. 예: 가격·주행거리에 천 단위 구분자 적용.
3. 차량 추가 화면, 입력 검증, 서버 처리, JSON 저장을 작은 단계로 구현합니다.
4. 기존 목록·상세가 작동하는지, 서버 재시작 후에도 저장되는지 확인합니다.
5. 시간이 남으면 검색·정렬·정보 수정 등 개인 기능 하나를 추가합니다.

구체적인 요청 예시와 검증 항목은 [실습 안내](docs/EXERCISES.md)를 보세요.
기본 반응형 배치와 오류 처리는 이미 들어 있으므로, 없는 기능이라고 요청하기 전에 현재 코드를 확인하세요.

## 테스트와 변경 확인

```sh
npm test
```

등록 구현 후에는 405를 기대하는 기본 테스트도 새 동작에 맞게 바꿉니다.
파일 저장 테스트는 임시 파일을 사용해 기본 차량 데이터를 망가뜨리지 않도록 합니다.
테스트 통과만으로 끝내지 말고 브라우저에서도 목록·상세·입력 동작을 확인하세요.

VS Code에서 변경 파일을 확인하세요. 큰 변경 전에는 프로젝트 폴더를 복사해 백업해 두면 되돌리기 쉽습니다.
`data/cars.json`에는 가상 차량 정보만 입력하고, API Key·비밀번호·실제 개인정보를 소스나 데이터에 넣지 마세요.

이 프로젝트는 개인 컴퓨터에서 실행하는 수업용 로컬 서버입니다. 기본 주소는 `127.0.0.1`입니다.

## 문제가 생기면

- `node`가 인식되지 않으면 설치 후 VS Code를 완전히 닫았다 다시 엽니다.
- `package.json`을 찾지 못하면 터미널이 이 파일과 같은 폴더인지 확인합니다.
- 3000번 포트가 사용 중이면 이전 서버를 Ctrl+C로 종료합니다.
- 다른 포트가 필요하면 PowerShell에서 `$env:PORT = '3001'` 실행 후 `npm.cmd start`를 실행합니다.
- 화면만 열리고 데이터가 안 나오면 Node.js 서버 주소로 접속했는지 확인합니다.
- JSON 오류는 VS Code의 `data/cars.json`에서 쉼표·따옴표·배열 구조를 확인합니다.

프롬프트를 여러 번 보내기 전에 터미널 로그와 변경 파일을 먼저 확인하세요.
