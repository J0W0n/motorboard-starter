# 30분 실습: 기존 프로젝트를 AI와 함께 확장하기

## 1. 실행하고 이해하기 · 4분

`npm start`로 실행하고 목록에서 차량 두 대를 각각 선택합니다.
가격·차량명·판매자 정보가 서로 다른지 확인하세요.

요청 예시:

> 아직 코드를 바꾸지 마. README와 프로젝트 파일을 읽고 목록·상세 화면이 JSON 데이터를 보여주는 흐름을 설명해 줘. 화면 코드, 서버 코드, 데이터 파일을 구분하고 관련 파일을 알려 줘.

설명을 실제 파일과 비교합니다. AI가 언급한 파일이 존재하는지 확인하세요.

## 2. 작은 개선 하나 · 4분

기본 제공본은 가격과 주행거리를 구분자 없이 표시합니다.
공통 함수가 목록과 상세에 함께 쓰이는지 찾아보세요.

> 차량 가격과 주행거리에 천 단위 쉼표를 표시해 줘. 예를 들어 1820 만원은 1,820 만원, 32400 km는 32,400 km로 보여야 해. 목록과 상세 모두 같은 규칙을 사용하고 JSON 숫자는 바꾸지 마. 수정한 파일과 확인 방법을 설명해 줘.

확인: 두 화면의 표시가 바뀌고 JSON에는 숫자가 그대로 남아 있어야 합니다.

다른 후보는 카드의 가격 강조 또는 옵션 표시 방식 개선입니다. 처음에는 하나만 합니다.

## 3. 차량 등록 계획 · 3분

> 기존 구조를 유지하면서 차량 등록 기능을 추가하려고 해. 아직 수정하지 말고 화면, 서버 API, JSON 저장 순서와 수정할 파일을 계획해 줘. 외부 패키지나 DB는 추가하지 마. docs/DATA.md의 기존 필드와 상세 화면이 깨지지 않게 해 줘.

입력 항목은 차량명, 제조사, 연식, 가격(만원), 주행거리(km), 지역, 설명을 기본으로 합니다.
나머지 기존 필드는 폼의 선택값 또는 문서에 정한 기본값으로 채웁니다.
사진 업로드, 실제 로그인, 결제, 이메일 발송은 이번 과제 범위에 넣지 않습니다.

## 4. 등록·저장 구현 · 10분

한 번에 모두 맡기지 말고 두 단계로 요청합니다.

> 먼저 기존 디자인에 맞는 차량 등록 페이지와 목록의 진입 링크를 만들어 줘. 각 입력 항목에 label과 단위를 표시하고, 누락이나 잘못된 숫자를 안내해 줘. 아직 저장 API가 없으므로 성공했다고 표시하지 마.

화면을 확인한 뒤:

> POST /api/cars와 JSON 파일 저장을 구현하고 등록 폼을 연결해 줘. 서버에서도 필수값과 숫자 범위를 검사하고, 중복되지 않는 ID를 만들어 줘. 서버에서 성공 응답을 받은 뒤 목록에 반영해 줘. 새로고침·서버 재시작 후에도 유지되어야 해. 기존 JSON 필드와 조회 기능을 유지해 줘.

실제 관리자 인증은 구현 범위가 아닙니다. 로컬 실습용 등록 화면입니다.
ID는 배열 길이만으로 만들지 않으며, 파일 저장 도중 기존 데이터를 잃거나 동시 요청이 서로 덮어쓰지 않도록 AI에게 처리 방법을 설명하게 하세요.

## 5. 검증하고 기록하기 · 5분

- 정상 입력 시 새 차량이 목록과 상세에 표시되는가?
- 차량명 누락, 음수 가격, 숫자가 아닌 주행거리를 거절하는가?
- 폼뿐 아니라 서버에서도 잘못된 입력을 거절하는가?
- 기존 차량들이 사라지지 않았는가? 차량 ID가 중복되지 않는가?
- `data/cars.json`에 새 차량이 실제로 들어갔는가?
- 서버를 종료하고 다시 실행해도 등록한 차량이 남는가?
- 저장 실패 시 성공 안내가 나오지 않는가?
- 기존 목록·상세·모바일 화면은 계속 작동하는가?

> 변경 파일을 검토하고 기존 조회 기능에 영향을 주는 부분을 설명해 줘. 기본 테스트 중 POST가 405라고 가정한 항목은 새 요구사항에 맞게 바꾸고, 검증 실패와 재시작 후 저장을 확인할 방법을 알려 줘. 파일 저장 테스트는 임시 데이터를 사용해 줘.

VS Code에서 변경된 파일과 코드를 확인합니다. 다음 기능을 추가하기 전에는 정상 동작하는 프로젝트를 복사해 백업할 수 있습니다.
이해하기 어려운 코드는 역할을 설명하도록 요청하고 실제 코드와 비교하세요.

## 6. 여유가 있으면 개인 기능 · 4분

검색, 가격순 정렬, 차량 정보 수정, UI 개선 중 하나를 선택합니다.
공통 과제가 끝나지 않았다면 새 기능 대신 등록·저장을 마무리합니다.

## 발표자 메모

기본 코드 분석 → 작은 개선 → 등록·저장 → 기존 동작 확인 흐름을 유지합니다.
설치·Copilot 활성화·최초 실행은 수업 전에 확인합니다.
시간이 부족하면 개인 과제를 생략하고 저장 검증을 우선합니다.
학습 목표는 AI가 어떤 변경을 했는지 사람이 이해하고 확인하는 것입니다.
